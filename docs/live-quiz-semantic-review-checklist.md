## 2. 语义审校 Rubric（逐题可用）

对每一题，建议按下面维度打勾或写一句批注。

### 2.1 题干（`question.text` / `prompt` / `title`）

- [ ] **情境具体**：读者能想象场景，没有过度依赖未交代的前提。
- [ ] **立场清晰**：问的是「你会怎么做」还是「你更认同哪种价值观」，不混问。
- [ ] **无诱导**：题干不明显偏向某一选项（道德绑架、唯一「政治正确」答案）。
- [ ] **IP/文化语境正确**（若适用）：时代、称谓、剧情设定与作品一致。

### 2.2 选项集合（同一题内）

- [ ] **互斥**：四个选项代表不同反应路径，而非同义反复。
- [ ] **覆盖面**：大致覆盖常见反应类型（不必数学穷尽，但避免三个都像、一个离谱）。
- [ ] **长度/语气均衡**：避免某一选项明显更长或更「标准答案腔」。
- [ ] **文案可读**：无歧义代词、无逻辑跳跃（尤其隐喻题：花/咖啡/城市等）。

### 2.3 选项与计分（`scores` / `value`）

- [ ] **得分与叙述一致**：选项文字表达的倾向，与正/负分方向一致（双极题尤其要对照 `lowPole` / `highPole`）。
- [ ] **双极题**：单选项最多两维、且**不出现一正一负混号**（除非产品明确支持；当前管线规则是不允许）。
- [ ] **加权题**：多维度同时加分时，是否**每一项都在叙述中有依据**（避免「为凑分硬加维」）。

### 2.4 `reaction`（若有）

- [ ] 与选项正文**不矛盾**，且能帮助用户理解「选了这个意味着什么」。

### 2.5 结果页（每个 `result`）

- [ ] **与维度画像一致**：长文描写的主气质，与 `dimension_profile` 的高峰维一致（加权）。
- [ ] **可区分**：与其它结果相比，是否有**至少一段**让人记住的差异（不仅是换城市名/人名）。
- [ ] **引用与事实**：名言、作者、作品典故**不要轻易张冠李戴**；不确定则改为泛化表达或去掉署名。
- [ ] **字段完整**：若通用结果页依赖 `strengths` / `weaknesses`，缺了会显得「半成品」（见下文 `spiritual-homeland-match`）。

## 3. 精读级语义评语（高风险套题）

以下按**内容语义**写结论；其中多处与机器报告中的结构错误**同源**（例如双极混号 = 同一句叙事既像「刚烈」又像「权谋」）。

### 3.1 `langyabang-character-match`（琅琊榜角色匹配）

**整体**：朝堂/友情/证据类情境写得**成熟、可读性强**，四选项在叙事上区分度不错，**单看文案质量是偏上的**。

**语义与计分结构的主要矛盾**：

1. **轴标签与得分方向**  
   维度名是「道义↔权谋」「情义↔算计」「隐忍↔刚烈」，但 `dimensionAxes` 里**只有 `lowPole`，缺少 `highPole`**（机器报 missing highPole）。  
   **语义后果**：用户端若用两极标签展示，**正向那一极没有独立名字**，只剩 `lowPole` + `highInsight`，读者难以理解「我正分到底代表哪一极」。

2. **双极题却大量「一题两维、且常混号」**（机器报告后半段集中爆发）  
   例如前几题里，同一选项在「道义↔权谋」与「隐忍↔刚烈」上**同时强正或强负**。  
   **语义后果**：用户选的是**一个具体行为**，却被强制同时映射到两个独立价值观轴；很多行为在现实中**可以权谋但仍刚烈、或重情义但仍隐忍**，模型却用固定符号强行绑定 → **题面像「道德剧」、得分像「硬编码」**，角色匹配容易失真。  
   **建议方向**（语义+结构）：要么改为加权多维（允许一行为多轴各给分档），要么双极题**每题只激活一轴**、或减少每选项的维度数。

3. **不可达结果**（机器：多结果被另一结果全面占优）  
   **语义后果**：某些角色结果**几乎永远不会出现**，用户会觉得「怎么总是那几个人」——这是**产品诚信问题**，不是润色能解决的。

**抽样题干**：如「皇帝欲以无辜之人平息叛乱询问你的意见」——四选项从直谏到借刀杀人，**戏剧张力足够**；问题在于**映射到多维双极的方式**而非单句中文。

---

### 3.2 `flower-personality-match`（花卉人格）

**整体**：隐喻统一（「你是某朵花」），**文学感强**，适合目标受众。

**语义与计分的主要问题**：

1. **双极规则与文案设计冲突**  
   例如 **q1 选项 d** 同时动到「存在方式 / 时间关系 / 社交气质」**三个维**，且存在正负组合 —— 在现行双极实现下属于**规则违规**，语义上则像把「担心不被接纳而守护」**强行拆成三条轴**，其中「时间关系」与句意**关联偏弱**，有**凑维度**感。

2. **q2「你是荷花」**  
   选项 b「利用宽大的荷叶，为小鱼提供阴凉」——在常识里荷叶与「小鱼」组合略跳脱（更常见是遮鱼或写莲下鱼戏），**略损沉浸感**，但不致命。

3. **不可达结果多**（机器报告）  
   部分「花/人格」结果在向量上被其它结果**全面压制** → 用户**永远测不到某些花**，与文案再美无关，需先改 profile / 打分分布。

**结论**：**文案层可读性好**；**主要风险在「一选项多轴 + 双极混号」与结果可达性**，属于要先修模型再细修比喻。

---

### 3.3 `love-level-test`（恋爱成熟度类）

**整体**：情境贴近约会/冲突/脆弱分享，**通俗、好懂**。

**语义与计分设计上的核心矛盾**：

1. **几乎每题每个选项只给单一维度 +2，其它维为 0**  
   例如 q1：四个选项分别只推高「情感表现 / 关系管理 / 恋爱成熟 / 自我认知」之一。  
   **语义后果**：同一道题里四种成熟反应**被设计成完全正交**，现实中「转移话题问对方」往往同时涉及边界与关系技巧，**非单一维**；用户会感到「怎么选都像在给自己贴一个孤立标签」。

2. **`scoring.dimensionAxes` 写法像双极（有 `lowPole` + 单一 `insight`），但 `type` 为加权**  
   **语义后果**：结果页若按「高/低极」解读，**缺少对侧的 `highPole` / 分侧 insight**，叙述容易**只批评不肯定**或**只肯定不批评**（视前端如何用字段）。

3. **机器报告中的 profile / 相似度 / 不可达**  
   与上述「每题只推一维」强相关 —— 向量空间稀疏，**结果容易挤在一起或某些结果永远输**。

**结论**：**日常语义 OK**；**量表设计更像 MBTI 式四槽而非连续成熟谱**，若产品定位是「成熟度连续体」，需要**重做得分逻辑**而不只是改句子。

---

### 3.4 `spiritual-homeland-match`（精神故乡 / 城市）

**整体**：场景（书店、咖啡馆、巷弄）**画面感好**，与「城市气质」主题一致。

**具体问题**：

1. **结果缺 `strengths` / `weaknesses`**（机器报告全结果警告）  
   **语义/产品后果**：通用结果页若默认展示优劣清单，会显示**空白或异常**，用户感觉**结果页没做完**。

2. **引用署名风险（需人工核实）**  
   例如结果 **r1（京都）** `verseSource` 为「村上春树」，配句为泛哲理中文。  
   **语义风险**：若该句**并非真实引文**，属于**伪引用** —— 建议改为「原创文案」或核对出处后改写。

3. **选项与维度**  
   单选项常只打一维（如仅「时间感知方式」），**语义上可接受**（场景题）；但需确认**各城结果画像差异足够**，否则用户会觉得「选啥都像文艺青年」。

---

### 3.5 `which-literary-giant-are-you`（文学巨匠匹配）

**整体**：问题从阅读反应、灵感来源等切入，**与「文学气质」主题高度一致**，选项区分度较好。

**语义注意点**：

1. **分数用小数（如 0.8、1.2）**  
   与纯整数加权题并存时**无语义错误**，但编辑时要**统一规则**（否则手改时难直觉判断强弱）。

2. **机器报告：某维度「得分机会过少」**  
   **语义后果**：某一文学维度在全套题里**很少被推高**，对应大师结果**名存实亡** —— 用户会觉得「怎么永远测不到某某流派」。

---

### 3.6 `coffee-personality-match`（咖啡人格 · 双极）

**整体**：轴名（强度、社交、节奏、感官）与咖啡语境**贴切**。

**语义与 schema 问题**：

- 轴上用了 **`insight` 单字段**，而校验期望 **`highInsight` + `lowInsight`**（机器报 missing lowInsight）。  
  **语义后果**：若前端分别展示「选温和端 / 强烈端」的解读，**可能缺失一整侧文案**，用户只看到一半解释。

- 大量选项 **超过 2 维、或混号**（机器报告）→ 与 `langyabang`、`flower` 同类：**叙事合理但模型假设过强**。

---

### 3.7 `pokemon-personality-match`（宝可梦）

**整体**（抽样前几题）：日常情境（周末、团队合作、迷路、聚会）**通顺、好懂**，与低龄/全年龄向 IP **兼容**。

**语义与产品诚信**：

- 机器报告：**多个结果不可达** → 某些宝可梦类型**几乎不会出现**。  
  **用户语义**：「我明明很像 X，为什么永远测不出」—— 必须先修 **profile / 分数矩阵**，再谈俏皮文案。

### 5.1 `buendia-generation-match`

- **语义气质**：魔幻现实、马孔多意象准，题干与《百年孤独》梗（磁铁、十一年雨季等）**贴合**。
- **选项**：四选一覆盖理性/迷信/传承/实用，**区分度好**。
- **注意**：与所有双极多维题一样，**同一行为被同时钉在两轴上**时，用户可能觉得「我只是务实，不代表对记忆的态度」——属**模型假设**问题，不单是文笔。

### 5.2 `ancient-poet-match`

- **明显文案问题**：**q1 选项 b** 正文为「独自品酒，静思冥想」，**reaction 为「独酌无趣」**——「无趣」与「静思」**语义冲突**，易让用户觉得系统贴错标签。
- **q1 选项划分**：共饮 / 独酌 / 雅集 / 封存待明日，**维度清楚**；但独酌一侧建议改 reaction 为中性词（如「独酌自适」）。
- **其余**：送别、朝堂等题**古风一致**；仍受双极混号/多维规则影响（见机器报告）。

### 5.3 `detective-conan-character-match`

- **情境**：钟楼毁证、证人拒证等，**柯南式推理剧语境正确**。
- **选项逻辑**：冲动制止 vs 埋伏取证 vs 观察 vs 现身说教，**路径分明**。
- **语义细节**：q1 **d**「用推理揭露并给予改过机会」偏**柯南/金田一式理想化**；若用户选此项，与「自我暴露」+1 是否总能对应，**略依赖读者是否认同「说教算暴露」**——可接受的小模糊。

### 5.4 `spirited-away-character-match`

- **设定**：汤屋、汤婆婆、无工威胁，**与原作设定一致**。
- **q1**：模仿他人 / 问路 / 直觉探索 / 躲藏，**覆盖常见适应策略**，语义顺。
- **q2**：顺从 / 冷静沟通 / 交换条件 / 逃跑，**权力博弈层次清楚**。
- **注意**：部分题会出现**第三维度**（如「给予索取模式」）与双极规则冲突（机器报告）——**结构上需收敛维数**，语义本身问题不大。

### 5.5 `one-piece-character-match`

- **航海情境**：暴风雨偏航、古日志高价等，**符合海贼冒险叙事**。
- **q1**：坚持航线 vs 随波逐流 vs 开会 vs 闯新航路，对「自由/集体/强者」的映射**直观**。
- **q2 选项 d**「复制或偷取日志」：**道德上负面**；若产品希望保留，需在结果文案中接纳「不择手段」型人格，避免结果页全是阳光表述——属**价值一致性**检查点。

### 5.6 `zootopia-character-match`

- **两轴题**（理想主义/犬儒 × 遵从/颠覆）：选项在「停案、暗访、独立调查、树洞拆迁」等**政策伦理情境**里**清晰**。
- **语义**：与电影「体制 vs 真相」母题**一致**；**通读抽样未发现明显 reaction 与正文矛盾**。
- **仍存**：机器报告中的双极违规与警告需**结构修复**后再做终稿润色。

### 5.7 `spending-personality-test`

- **消费场景**：限量外套、周末安排等，**贴近真实**。
- **严重结构语义纠缠**：**q1 选项 a** 同时打 **三个维度** 且正负混杂（如「立即刷卡」对应 体验/物品、即时满足、实用/审美 多向拉扯）——**用户无法直觉理解「这一下子说明了什么」**。
- **建议**：此类题要么改为**加权**且每选项最多 2～3 个明确动机标签，要么拆成多题；否则语义上永远「像被算法拽着走」。

### 5.8 `cthulhu-deity-match`

- **意象**：宇宙镜、深海存在等，**克系氛围足**。
- **结构**：**q1 选项 b/c** 等单选项打 **4 个维度**（机器报告重灾区）——**叙事再美也会让用户觉得「我怎么同时是 A 又是 B」**。
- **语义**：选项 d「宇宙观: 0」若大量出现，会削弱区分度——需编辑统一是否允许 0 分档。

### 5.9 `自媒体赛道人格测验`

- **题干与选项**：创作流程、瓶颈、差评处理等，**行业语义准确、口气统一**。
- **q1.d**：「完美主义者」仅 **创意表达 +1**（余选项常 +2），**力度偏弱**——用户可能觉得「拖延/等待氛围」没被足够采样；属**平衡性**而非病句。
- **产品**：机器报告 **r6 不可达、r7↔r9 过近**——部分赛道**永远测不到或撞车**，需改 profile，不单改文案。

### 5.10 `tang-poets`

- **语义**：现代梗「**刷一会儿手机**」插在唐诗气质题里——若是**刻意反差幽默**可保留；若定位严肃古风，则**破坏沉浸**，建议二选一统一调性。
- **内容**：月光窗台、远行邀约、路人施舍等题，**与李白/杜甫/王维/白居易维度映射直观**，抽样**无明显 reaction 错误**（本题无 reaction 字段）。

### 5.11 `classic-book-match`

- **结果**：r1、r9 **不可达**（机器）→ 某几部「名著气质」结果**名存实亡**，与文案好坏无关。

### 5.12 `avengers-hero-match`

### 5.13 `paladin-character-match`
