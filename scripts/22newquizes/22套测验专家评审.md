# `22newquizes` 测验详细专家评审（对照市面标杆）

**评审日期**：2026-04-06  
**范围**：目录内 22 个 JSON；`relationship-fidelity-test.json` 与 `relationship-fidelity-test 2.json` **逐字相同**，实质 **21 套**独立内容。  
**阅读深度**：已通读每套的 `description`、`scoring`（含全部 `dimensionAxes`）、**全部题干与选项**（18～22 题/套）、抽样通读结果长文案；对计分与维度定义做交叉核对。  
**对照对象**：市面「最优档」趣味/人格类测验的常见做法——包括 **16Personalities**（清晰维度、中立题干、结果具体）、**IDRlabs / IPIP 系**（诚实标注非诊断、减少社会赞许偏差）、**BuzzFeed / The Pudding**（强叙事、选项等距、少道德审判）、**日台综艺式心理测验**（一题一轴、结果可分享且不羞辱用户）、**国内头部小程序测验**（本土化场景、避免重复卷、导语管理预期）。

---

## 一、市面一流测验的参照标准（本评审的「尺子」）

1. **预期管理**：开篇区分「娱乐 / 自我探索」与「专业心理评估」；不用「诊断」「真实人格」「准确度」除非有量表授权与信效度数据。  
2. **题干质量**：单一焦点，避免一道题里同时测两件事；情境具体但**不绑架道德**（少「选了就等于你是坏人」）。  
3. **选项设计**：四个选项尽量**等距**（同样具体、同样长度阶），减少「明显政治正确项」导致全选 A。  
4. **计分逻辑**：维度名、`highPole`/`lowPole` 文案、题目得分方向三者**严格同向**；多轴题注明各轴独立。  
5. **区分度**：同一卷内**少重复情境**；相似题应合并或改写成不同切面。  
6. **结果页**：少「你总是/你从不」；多「你往往/在压力下更容易」；给**可行动的一小步**而非定性人格判决。  
7. **敏感议题**：出轨、恐惧、原生家庭等——避免羞辱、避免暗示「低分=道德失败」；可加轻量支持性提示。  
8. **文化/IP**：人名、典故、游戏设定与**大众常识**一致；避免张冠李戴（天庭 vs 历史人物等）。

以下逐套对照上述标准，标出**硬伤（破坏效度或会误导用户）**、**瑕疵（影响体验）**、**优化方向**。

## 二、本批数据的系统性问题（跨卷）

| 问题 | 表现 | 建议 |
|------|------|------|
| **导语过度承诺** | 多份写「评估」「真实水平」「诊断」 | 统一改为「趣味情境选择」「反映当下倾向」 |
| **社会赞许偏差** | 道德情境里「高尚选项」过强，易全选同一象限 | 增加「同样体面但策略不同」的选项，或改用「你更累的是哪一端」式表述 |
| **同主题重复上架** | 「抗出轨/边界」至少三套 + 题面大量重复 | 合并或强差异化（只保留一套长线版） |
| **重复文件** | `relationship-fidelity-test 2.json` | 删除，避免维护分叉 |
| **人称不统一** | 同卷混用「你」与「您」 | 统一为「你」或「您」（全产品一致即可） |
| **reaction 与行为不符** | 如「冷眼旁观」对应「社会制度思考」 | 校对 reaction 标签与选项语义 |

## 三、逐套详细意见

### 1. `who-in-les-miserables.json`（悲惨世界角色）

**维度**：`个人理想与现实的冲突` × `自我救赎的方式`（双极），映射多名著人物——设计思路与 IP 匹配。

**导语**：「雨笔下」为**错别字**，应为「雨果笔下」。

**逐题要点**：

- **q1**：d「记录并思考制度压迫」却标 reaction「冷眼旁观」——**文案与行为矛盾**（更接近知识分子介入，而非冷漠）。  
- **q2 / q7 / q13**：均围绕「无辜者被冤」——**高度重复**，仅细节不同，浪费题位、放大随机误差。  
- **q7 vs q2**：q7 的 b「静待时机」与 q2 的 c「匿名证据」同属策略型正义，但得分同为负向理想/救赎，**对「策略性正义」不友好**，与冉·阿让式隐忍救赎不一致。  
- **q9 vs q16**：均为「阶级/价值观与爱情」——**重复维度**。  
- **q10 vs q18**：均为「过去错误伤害无辜如何补救」——**重复**。  
- **q14 d**：「同情但认为不如改变社会结构」——语义上接近**结构性理想主义**（偏街垒青年），却记 `个人理想与现实的冲突: -1`、`自我救赎: -1`，**与维度定义冲突**（更像高理想而非低理想）。属**计分逻辑硬伤**。  
- **q11 a**：「暴力革命」记理想冲突 0、救赎 2——可讨论，但需在结果页解释，否则用户困惑。

**结果页**：冉·阿让等 portrait 质量高；爱潘妮等含**情节结局**（街垒、死亡），对未读者为**剧透**。

**与标杆差距**：人物卷应像「Pottermore 分院」——每题测**不同切面**（忠诚/谎言/牺牲/法律观各一题），而非同一道德题变体五次。

**建议**：合并冤案/爱情/救赎类重复题；修正 q14d 分数或改写选项文本；统一人称；修正 q1d 的 reaction；简介改「雨果」；结果加「含原著情节」提示。

### 2. `middle-earth-character.json`（中土世界角色）

**硬伤（维度轴文案）**：`力量观` 的 `lowPole`「谦逊节制」、`highPole`「强大掌控」，但 `highInsight` 写「谨慎使用力量、智慧重于武力」、`lowInsight` 写「依靠智慧与毅力、精神力量」——**两极释义都与「强大掌控」不对齐，且彼此接近**。用户读到结果会认定系统错了。

**逐题要点**：

- **q1**：力量维度：丢戒指 −2、野心 +2——与题干编码一致，但与 **axis 文案矛盾**（轴层面问题）。  
- **q7**：b「撤退保存实力」记 `面对黑暗: -2` 且 `责任态度: -1`——**把战术撤退等同于恐惧与不负责任**；刚铎/精灵战争里撤退常为理性，**污名化审慎**。  
- **q9**：b「民主协商、少数服从多数」记 `自由与秩序: -2`、`责任态度: -1`——**民主协商≠无序**，且不应默认损害「责任」；价值观偏见明显。  
- **q6**：d「不惜生命使用力量」记 `力量观: +2`——与 q1「野心重塑秩序」同向，尚可；但与「谦逊」角色（弗罗多）的映射需靠其他题拉平。

**与标杆差距**：顶级 IP 测验会避免**把一种政治/军事策略道德化判分**；轴文案会先定稿再写题。

**建议**：重写 `力量观` 整轴（或交换 high/low 文案与题目符号）；修订 q7b、q9b 的维度归属或选项表述。

### 4. `tarot-card-type.json`（你是哪一种塔罗牌）

**P0 级硬伤——`稳定vs变化` 轴方向与 `dimensionAxes` 极可能整轴反接**：

- 轴定义：`lowPole` =「稳定渐进」，`highPole` =「变革突破」——通常实现为 **分数高 → 对应 highPole**。  
- **q3**：「逐步稳定、小范围改变」记 **`稳定vs变化: +2`**；「果断打破常规」记 **`-2`**。即 **正分 = 偏稳定**。  
- **q6**：「坚守日常规律」记 **`+2`**；「积极准备迎接变化」记 **`-2`**。同样 **正分 = 稳定**。  

若引擎规则是「维度总分高 → 展示 highPole 文案」，则**偏好稳定的用户会被贴上「拥抱变革」**，与 q3、q6 语义完全相反。请用同一套规则跑一个「全选稳妥项」的用户，核对落地结果是否错位。

**其他逐题**：

- **q4 / q7**：`内在vs外在` 编码与轴文案一致时需同样用假用户测一遍。  
- **q7 d**：「完全按内心冲动」同时扣 `理性vs直觉 -2`——将冲动归为「理性轴」负端，可接受但结果页应解释「直觉≠冲动」。  

**与标杆差距**：The Pudding 类测验会在发布前做**反向用户测试**（全选一端看标签）。

**建议**：要么交换 `稳定vs变化` 所有题目分值的符号，要么交换 `highPole`/`lowPole` 与两条 Insight 文本；并做一次端到端验收。

### 19. `relationship-fidelity-test.json`（抗出轨能力）与 `relationship-fidelity-test 2.json`

两文件**逐字重复**——删 `2.json`。

**重复题面（全卷 18 题内）**：

- **q5 ≈ q11**：同事趁伴侣低落提供「情感支持」越界——**题干高度重复**。  
- **q7 ≈ q15**：商务旅行、客户晚餐后邀次日单独见面——**选项结构几乎一致**。  
- **q9 ≈ q17**：聚会上伴侣与他人亲密 + 第三人暗示邀请——**同一剧本**。  
- **q10 ≈ q16**：社交媒体粉丝/赞美、希望私下交流——**同一剧本**。  
- **q12 ≈ q18**：前任仍有吸引力 + 伴侣忙于他事——**同一剧本**。

上述重复使有效题数约减半，得分信度下降，违背一流测验「每题测不同触发点」的做法。

**计分语义**：

- **q1 c**「仍见面但保持朋友距离」在已有暧昧明示下，仍给 **`边界意识 1` + `诱惑抵抗力 1`**——对多数伦理框架仍属**高风险**，分数偏高。  
- 多套题中「礼貌拒绝但不告诉伴侣」反复出现——可保留，但应明确「透明度」是否独立维度。

**与标杆差距**：好的关系边界测验会包含「开放式关系/多角」等多元关系语境（若产品允许），避免默认全员单偶；至少导语说明假设语境。
